# Paytick

Paytick 是一款 macOS 菜单栏工资计算器。设置月薪和工作时间后，可以查看工作期间累计的估算收入，并通过菜单栏打开详情面板。

## 功能

- 根据月薪、工作日和工作时间估算收入，显示在菜单栏和详情面板中。
- 默认估算中国大陆广州企业职工个人社保和工资个税，显示税前、社保、个税和税后金额。
- 可调整社保申报基数、每月专项附加扣除及计税月份，也可关闭自动扣除。
- 支持隐私显示、愿望目标和加班提示。
- 左键菜单栏项目打开或关闭面板，右键打开退出菜单。
- 工作时间内可点击「提早下班」，按当日应得收入减去已得收入一次性结算，并查看当月累计。每天最多记录一次，结算记录保存在本地；金额沿用当前税前或税后设置。

## 税后估算说明

默认社保模型使用代码中保存的广州 2026 年个人缴费比例和各险种基数上下限：养老 8%、医疗 2%、失业 0.2%。个税按固定月薪的累计预扣模型估算，基本减除费用为每月 5,000 元。公积金未计入。

计算假设本年度此前月份的工资、社保和专项附加扣除与当前设置相同；计税月份首次默认为当前月份，之后使用保存的设置。换工作、收入变化、奖金、公积金或其他扣除等情况可能导致结果与工资条不同。政策和缴费基数会调整，结果仅供参考，请以实际工资条和当地现行政策为准。

## 构建和运行

需要 macOS 14 或更新版本以及 Xcode。克隆仓库后，用 Xcode 打开 `Paytick/Paytick.xcodeproj`，选择 `Paytick` scheme 并运行。

也可以在仓库根目录执行：

```sh
xcodebuild -project Paytick/Paytick.xcodeproj -scheme Paytick -configuration Debug build
```

应用运行后常驻菜单栏。在面板中设置月薪和工作时间，并在个人信息设置中调整工资扣除参数。

## 测试

```sh
xcodebuild -project Paytick/Paytick.xcodeproj -scheme Paytick -destination 'platform=macOS' test
```
